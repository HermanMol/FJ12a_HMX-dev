# What is here?

- hmx_spool*.sql files: Start a unique spoolfile name, pause and resume spooling to a spoolfile and run a script with output spooled.
- prt: Just a simple efficient alias for the lengthy original
- hmx_call_stack: package with wrappers around UTL_CALL_STACK modules
- hmx_operators: operator objects
- hmx_session: a.o. wrapper for dbms_session
- hmx_utl: package with utilities
- string_stack_class: An oracle database type with methods to handle the 50 entries in a 4000 character varray.
- templates: database object source (ddl) templates
