# In SqlPath
This folder contains files used on the SQLcl client for maintaining the database
objects.
You may put these files (when needed) in any folder that can be found when
executing command line SQLcl scripts, commands, etc.

You might set the environment variable SQLPATH to include the folder containing
the files in this folder.
